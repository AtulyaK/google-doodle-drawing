# Lantern Ink Atelier

Lantern Ink Atelier is a self-contained static showcase for an original
alchemy-stencil experience. It explores the mood of careful craft, ink,
apprenticeship, and illustrated fantasy without adapting protected material.

This is not official *Witch Hat Atelier* artwork or a game asset collection.
It does not copy characters, symbols, panels, costumes, settings, terminology,
or story material from that work. The project name, copy, compositions, and
SVG illustrations were authored for this repository.

## Contents

- `index.html` - the standalone showcase page
- `styles.css` - local responsive styling with no build step
- `assets/moonwell-stencil.svg` - original guided-stencil illustration
- `assets/lantern-bloom-result.svg` - original completion illustration

No external images, fonts, scripts, or services are loaded. Serve the parent
repository with its existing local HTTP command and open:

`http://localhost:5173/projects/witch-hat-atelier/`
